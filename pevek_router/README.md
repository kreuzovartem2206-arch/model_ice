# Ледовый маршрутизатор Певек (пилот)

> **Карта на реальных данных** (прогноз 16–21.10.2026): `docs/index.html`. Демо на синтетике: `docs/demo_synthetic.html`.
> GitHub Pages можно включить из папки `docs`. Модель судна не откалибрована — это пилот, а не навигационная рекомендация.

Оптимальный маршрут для судна ледового класса **Л2** (ледопроходимость по ТЗ: до 0,5 м, до 5 баллов)
в Восточно-Сибирском море севернее основной трассы СМП: Певек, кромка паковых льдов (~76° с. ш.),
восточный ледяной массив, транзит от Новосибирских островов к проливу Лонга.
Критерии: **расход топлива** и **время в пути**. Входные поля: **сплочённость и толщина льда, волнение, ветер, течения**.

## Состав

| Файл | Что делает |
|---|---|
| `config.py` | Район, сетка (~4.5 км), опорные точки, маршруты, цена топлива, стратегии |
| `ship.py` | Модель судна Л2: сопротивление (тихая вода + ветер + волны STAWAVE-1 + битый лёд) → мощность → скорость и топливо; ограничения класса |
| `grid.py` | Сетка и маска суши (`global-land-mask`, ~1 км) |
| `loaders.py` | Загрузчики: ERA5 (CDS), Copernicus Marine ARC-MFC (TOPAZ5: лёд, течения; волновой прогноз), OSI SAF (сплочённость), CS2SMOS / Sea Ice CCI (толщина по CryoSat-2 и Sentinel-3) |
| `open_sources.py` | **Оперативный прогноз без регистрации**: NOAA GFS (ветер), GFS-Wave (волны), RTOFS (течения, толщина и эволюция льда), NCEP Sea Ice Analysis (сплочённость, наблюдения) → `env.nc` |
| `merge_topaz.py` | Подставляет в `env.nc` течения (и по желанию лёд) Copernicus TOPAZ5 из файла `copernicusmarine subset` |
| `fetch_data.py` | Архив/прогноз Copernicus + ERA5 (нужны учётки) → `env.nc` |
| `synthetic.py` | Синтетический сценарий 20–25 октября (только для проверки конвейера) |
| `router.py` | Время-зависимый поиск пути (16 направлений) с выбором скорости на каждом шаге, сглаживание, непрерывный пересчёт KPI |
| `run_pilot.py` | Расчёт: маршруты × сроки отхода × 3 стратегии + базовый вариант (кратчайший проходимый путь полным ходом) |
| `viewer.py`, `viewer_template.html` | Автономная HTML-карта с результатами |

## Быстрый старт

```bash
pip install -r requirements.txt
# демо на синтетике
python -m pevek_router.run_pilot --synthetic --out out
python -m pevek_router.viewer out/pilot_results.json out/pevek_router.html
```

## Реальные данные: оперативный прогноз (без регистрации)

```bash
python -m pevek_router.open_sources --out data_open          # ~5 мин, RTOFS качается глобальными файлами по 60–150 МБ
python -m pevek_router.run_pilot --env data_open/env.nc --out out_real --departures 0 24 48
python -m pevek_router.viewer out_real/pilot_results.json out_real/pevek_router_real.html
```

Сплочённость = наблюдение NCEP (последние сутки) + изменение по прогнозу RTOFS («прогноз аномалии»).
Толщина — RTOFS (CICE); где модель льда не видит, а спутник видит — молодой лёд 0,10 м.
NOMADS ограничивает частоту запросов, загрузчик делает паузы и повторы.

## Реальные данные: Copernicus + ERA5

```bash
pip install cdsapi copernicusmarine
# 1) ключ CDS в ~/.cdsapirc и принятая лицензия ERA5 на сайте CDS
# 2) copernicusmarine login
python -m pevek_router.fetch_data --start 2025-10-20 --end 2025-10-25 --out data \
       --cmems-phy auto --cmems-wav auto --osisaf \
       --thickness-file W_XX_ESA_SMOS_CS2_NH_25KM_EASE2_...nc   # необязательно, только зимой
python -m pevek_router.run_pilot --env data/env.nc --out out
python -m pevek_router.viewer out/pilot_results.json out/pevek_router.html
```

Приоритет источников: сплочённость — OSI SAF > TOPAZ; толщина — CS2SMOS/CCI > TOPAZ (у берега модель);
волны — прогноз CMEMS ARC > ERA5; ветер — ERA5; течения — TOPAZ.
Идентификаторы наборов внутри продуктов Copernicus меняются между версиями, поэтому `auto` выбирает их
через `copernicusmarine describe`; при ошибке укажите `dataset_id` явно.
Шаблон адреса OSI SAF (`loaders.OSISAF_URL`) сверьте с каталогом THREDDS met.no.

## Как считается

* **Стоимость шага** = цена топлива × топливо + ставка судна × время. Стратегии отличаются ставкой:
  «Быстрый» (время почти бесценно → минимум времени), «Сбалансированный» (18 000 $/сут),
  «Экономичный» (4 000 $/сут → снижение скорости и обход тяжёлых участков).
* **Скорость** выбирается на каждом шаге из 6, 8, 10, 11.5, 13 уз или максимально возможной при 90 % MCR,
  с ограничениями: во льду 1–3 балла ≤ 9 уз, 3–6 баллов ≤ 6 уз; добровольное снижение на встречной волне Hs > 3.5 м.
* **Ограничения судна** (самостоятельно): сплочённость ≤ 5 баллов, толщина ≤ 0,5 м (лёд < 1 балла не учитывается); Hs ≤ 6 м.
  Если пункт отхода или проход закрыты — выдаётся «нужна ледокольная проводка».
* **Время-зависимость**: условия берутся на момент прохождения ячейки (шаг 3 ч), с запасом на следующий срок.
  Каждый ход по сетке проверяется по всем клеткам, которые пересекает отрезок.

## Что калибровать перед реальным применением

1. Параметры конкретного судна (`ship.py`): кривая мощности/скорости, SFOC, ледовый паспорт.
2. Коэффициенты ледового сопротивления `k_break`, `k_moment` — по ледовому паспорту или натурным данным.
3. `c_wave` (множитель STAWAVE-1) — по судовым журналам или данным AIS + расход.
4. Батиметрия (IBCAO / GEBCO) — сейчас не учитывается, а Чаунская губа и подходы мелководны.
5. Припай и молодой лёд у берега: спутниковые анализы (~10 км) и модели его плохо разрешают;
   для Чаунской губы нужны снимки Sentinel-1 или ледовые карты ААНИИ.
6. Ожидание у кромки (дрейф/якорная стоянка) пока не моделируется: если проход закрывается в пути, вариант помечается как непроходимый.
7. Валидация: сравнить маршруты с реальными треками AIS за навигацию 2024–2025.

## Сравнение моделей течений и льда (прогон 16.10.2026)

Файл TOPAZ5 скачан командой (переменные `vxo`/`vyo` в этом наборе уже направлены на восток/север):
```
copernicusmarine subset --dataset-id cmems_mod_arc_phy_anfc_6km_detided_PT1H-i --variable vxo --variable vyo \
  --variable siconc --variable sithick --minimum-longitude 148 --maximum-longitude 180 --minimum-latitude 68 \
  --maximum-latitude 78.5 --start-datetime 2026-10-16T00:00:00 --end-datetime 2026-10-21T00:00:00 --output-filename topaz_pevek.nc
```

* Течения TOPAZ5 и RTOFS совпадают по направлению (косинусное сходство полей 0,91), но TOPAZ5 в 1,3–2 раза сильнее,
  особенно во время шторма 18 октября (95-й процентиль 0,84 против 0,49 м/с).
* На маршрутах это меняет время и топливо на 1–15 %, выбор трассы почти не меняется.
* Лёд TOPAZ5 даёт другую картину: у Новосибирских островов сплочённость 5,1 балла (выше предела судна),
  а к кромке 76° с. ш. проход закрывается раньше — эти маршруты для судна становятся непроходимыми.
  Расхождение моделей льда у кромки — главный источник неопределённости; нужна сверка со спутниковыми снимками.

Карты: `docs/topaz_currents.html` (течения TOPAZ5), `docs/topaz_currents_ice.html` (течения и лёд TOPAZ5).
