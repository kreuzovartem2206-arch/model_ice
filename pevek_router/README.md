# Ледовый маршрутизатор Певек (пилот)

Оптимальный маршрут для судна ледового класса **Л2** в районе Певека и на прилегающих участках СМП
(Восточно-Сибирское море: от Медвежьих островов до пролива Лонга).
Критерии: **расход топлива** и **время в пути**. Входные поля: **сплочённость и толщина льда, волнение, ветер, течения**.

## Состав

| Файл | Что делает |
|---|---|
| `config.py` | Район, сетка (~4.5 км), опорные точки, маршруты, цена топлива, стратегии |
| `ship.py` | Модель судна Л2: сопротивление (тихая вода + ветер + волны STAWAVE-1 + битый лёд) → мощность → скорость и топливо; ограничения класса |
| `grid.py` | Сетка и маска суши (`global-land-mask`, ~1 км) |
| `loaders.py` | Загрузчики: ERA5 (CDS), Copernicus Marine ARC-MFC (TOPAZ5: лёд, течения; волновой прогноз), OSI SAF (сплочённость), CS2SMOS / Sea Ice CCI (толщина по CryoSat-2 и Sentinel-3) |
| `fetch_data.py` | Скачивает данные за период и собирает `env.nc` |
| `synthetic.py` | Синтетический сценарий 20–25 октября (только для проверки конвейера) |
| `router.py` | Время-зависимый поиск пути (16 направлений) с выбором скорости на каждом шаге, сглаживание, непрерывный пересчёт KPI |
| `run_pilot.py` | Расчёт: 2 маршрута × 4 срока отхода × 3 стратегии + базовый вариант (кратчайший путь полным ходом) |
| `viewer.py`, `viewer_template.html` | Автономная HTML-карта с результатами |

## Быстрый старт

```bash
pip install numpy scipy pandas xarray netCDF4 global-land-mask
# демо на синтетике
python -m pevek_router.run_pilot --synthetic --out out
python -m pevek_router.viewer out/pilot_results.json out/pevek_router.html
```

## Реальные данные

```bash
pip install cdsapi copernicusmarine
# 1) ключ CDS в ~/.cdsapirc и принятая лицензия ERA5 на сайте CDS
# 2) copernicusmarine login
python -m pevek_router.fetch_data --start 2025-10-20 --end 2025-10-25 --out data \
       --cmems-phy auto --cmems-wav auto --osisaf \
       --thickness-file W_XX_ESA_SMOS_CS2_NH_25KM_EASE2_...nc   # необязательно, только зимой
python -m pevek_router.run_pilot --env data/env.nc --out out
python -m pevek_router.viewer out/pilot_results.json out/pevek_router.html
```

Приоритет источников: сплочённость — OSI SAF > TOPAZ; толщина — CS2SMOS/CCI > TOPAZ (у берега модель);
волны — прогноз CMEMS ARC > ERA5; ветер — ERA5; течения — TOPAZ.
Идентификаторы наборов внутри продуктов Copernicus меняются между версиями, поэтому `auto` выбирает их
через `copernicusmarine describe`; при ошибке укажите `dataset_id` явно.
Шаблон адреса OSI SAF (`loaders.OSISAF_URL`) сверьте с каталогом THREDDS met.no.

## Как считается

* **Стоимость шага** = цена топлива × топливо + ставка судна × время. Стратегии отличаются ставкой:
  «Быстрый» (время почти бесценно → минимум времени), «Сбалансированный» (18 000 $/сут),
  «Экономичный» (4 000 $/сут → снижение скорости и обход тяжёлых участков).
* **Скорость** выбирается на каждом шаге из 6, 8, 10, 11.5, 13 уз или максимально возможной при 90 % MCR,
  с ограничениями: во льду 1–3 балла ≤ 9 уз, 3–6 баллов ≤ 6 уз; добровольное снижение на встречной волне Hs > 3.5 м.
* **Ограничения класса Л2** (самостоятельно): сплочённость ≤ 6 баллов; при ≥ 3 баллах толщина ≤ 0.35 м; Hs ≤ 6 м.
  Если пункт отхода или проход закрыты — выдаётся «нужна ледокольная проводка».
* **Время-зависимость**: условия берутся на момент прохождения ячейки (шаг 3 ч), с запасом на следующий срок.

## Что калибровать перед реальным применением

1. Параметры конкретного судна (`ship.py`): кривая мощности/скорости, SFOC, ледовый паспорт.
2. Коэффициенты ледового сопротивления `k_break`, `k_moment` — по ледовому паспорту или натурным данным.
3. `c_wave` (множитель STAWAVE-1) — по судовым журналам или данным AIS + расход.
4. Батиметрия (IBCAO / GEBCO) — сейчас не учитывается, а Чаунская губа и подходы мелководны.
5. Припай: OSI SAF и TOPAZ его плохо разрешают; для Чаунской губы нужны снимки Sentinel-1 или ледовые карты ААНИИ.
6. Валидация: сравнить маршруты с реальными треками AIS за навигацию 2024–2025.
